# 固定偏置来源与坐标父子关系复核

2026-10-23。本文修正旧图将模型原点直接称为实物“躯干末端”、将拟合头系标成真实关节位置的歧义。控制器 MDH 仍是标定运动链依据；本次只修改可视化。

## 图1的三组数据从哪里得到

文件：`reference/LunaUdpTool/model/gento_luna/gento_luna_contact_filtered.xml`。虽然 model 名称含 URDF，实际文件是 MJCF。

其第57行的 `Gento Luna_Leg_J6_Link` 是三条支链的共同父 body。以下位置都是此父 body 坐标中的局部平移，文件单位为米，表中乘1000得到毫米；不是 world 位置、质心位置或标定测量值。

| 子 body / 零位安装系 | 文件行号 | pos，m | quat，wxyz | 近似旋转 |
|---|---:|---|---|---|
| Arm_R1_Link | 62 | 0 -0.2146 0.3915 | 0.707105 0.707108 0 0 | Rx(+90°) |
| Arm_L1_Link | 104 | 0 0.2146 0.3915 | 0.707105 -0.707108 0 0 | Rx(-90°) |
| Head_J1_Link | 146 | -0.013496 0 0.49898 | 0.707105 0.707108 0 0 | Rx(+90°) |

`pos/quat` 定义子 body 在关节零位相对父 body 的固定安装姿态；子 body 带活动关节，其运行时姿态还包含关节变换。这里“首关节之前”指零位安装变换，不是另有一个已声明的固定 link。

双臂首关节安装系也不等于 MDH 父系：当前名义换算为

`T_S_M = T_S_first_zero @ inverse(T_M_first_MDH(q=0))`。

控制器首段 D=158.6mm，使右/左 MDH 父系在原模型 S 下约为 `[0,-56,391.501]` / `[0,+56,391.501]`mm，旋转约 Rx(+90°)/Rx(-90°)。这是名义 CAD/MDH 对齐的推导，已有双臂全部七关节的几何一致性检查，不等同于实机测量。

## 两个头关节与相机

模型第151行 Head_J2_Link 未写 pos，默认零平移；第148/153行两个 joint 的 pos 也都是零。因此模型两个头关节原点重合，零位轴方向不同。不能因为壳体有上下两个结构，就将模型原点直接移到两个壳体中心。新图以 JH1/JH2 [CAD] 明确标记其真实文件定义，并用引线分开名称。

这些 MJCF 头关节的顺序不替代控制器的 yaw→pitch。控制器链应理解为：

```
选定躯干系 S
├─ 固定安装 → M_R → 右臂 MDH 链 → 右法兰
├─ 固定安装 → M_L → 左臂 MDH 链 → 左法兰
└─ 固定安装 → H_base（MDH父系，不是第一个电机中心）
   └─ 控制器 yaw → H_after_yaw
      └─ 控制器 pitch → H_after_pitch
         └─ 固定外参 X → C_L
            └─ 双目标定相对变换 → C_R
```

给定 MJCF 没有相机 body/site，故不能从它提取两眼光心相对头部末端的安装外参。双目标定能确定两眼相对关系（基线59.538mm），不能单独确定光心在头壳中的绝对位置。旧图 H0/H2 与 C_L/C_R 来自未批准的十二参数诊断拟合；本次将其默认隐藏，避免当作实机几何。
