# 当前坐标与机型约定

当前fit采用旧Luna V2.0混合六参数模型，`T_S_C = F_fixed Rz(yaw) Ry(-pitch) X`。S为Leg_J6_Link模型原点，右手系；输入角度deg，长度m，旋转向量内部rad。见[完整六参数说明](six_parameter_calibration.md)。

F_fixed取MJCF头部共同原点[-0.013496,0,0.49898]m，并显式假设零位轴与S对齐。MJCF原始Pitch→Yaw关节旋转不参与计算。原控制器D=640mm及头部Alpha不进入新混合链，不做加减抵消。H0为yaw，H1为pitch，H2只是预留接口。

旋转遵循前X、左Y、上Z约定；负yaw右转、负pitch低头。S轴向、实际零位和共心几何仍需独立实机核实。新链名luna_v2_hybrid；旧controller_mdh只用于历史v1模型兼容读取。

双臂仍使用luna_new.ini原控制器MDH：264/264mm、首段158.6mm、固定法兰87mm。FK包含法兰段，不可重复相加；左右臂MDH父系通过torso_mounts.json转换到S。内部数据target_m以右臂MDH父系记录，推理输出S。

校正左眼C的相对右眼外参为R=I、t=[-0.0595383553,0,0]m；正深度时uL-uR为正。当前相机外参X连接H1运动末端与校正左眼，包含校正旋转，不能额外乘一次R1。

原始鱼眼为2560×1984，校正测量为1280×992；raw接口接收原生鱼眼像素，使用原始K/D及R1/R2转到校正像素域。原始光学安装矩阵可由X @ R1得到，不能在校正像素推理时重复使用。

Marvin_pro的287/314mm、相机配置和外参都不用于Luna。复制源文件与哈希保持不变。历史十二参数A/X模型保留为只读对照，新模型不从其A取值。

固定安装配置与双臂安装配置哈希绑定到新模型；配置变更必须重拟合。训练、未见球位、未见头姿和跨会话评估分别记录，正式推理仍保留验收门禁。连续运动另需曝光/反馈同步验证；数学可连续求值不代表已完成运动中验收。
