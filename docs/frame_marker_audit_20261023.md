# 坐标标记复核与浅色视图（2026-10-23）

后续修正：下面是第一轮复核记录。最新视图默认隐藏拟合头/相机系，并区分模型原点与CAD接口参考；见[固定偏置来源与父子关系复核](frame_offset_sources_20261023.md)。

结论：S具有直接模型依据；双臂MDH父系是与所给MJCF臂链一致的名义安装推导；H0/H2与相机只能解释为未批准模型的有效拟合坐标，不能确认是真实安装。绘图颜色/方向约定为X红、Y绿、Z蓝。

## 复核结果

- S_TORSO：由MuJoCo的Gento Luna_Leg_J6_Link body位姿读取，是第6躯干关节之后的局部系，模型零位world位置约[0,0,865]mm。
- M_R/M_L：模型首关节安装乘控制器首段MDH变换的逆。S中位置约[0,-56,391.501]mm和[0,+56,391.501]mm。214.6-158.6=56，因此MDH父系位于胸内不自动代表画错；214.6mm对应的是首关节原点，不是MDH父系。
- 进一步对双臂全部7关节核对：在零位与非零关节构型下，控制器MDH预测的每个关节原点与轴向，与所给MJCF一致（以20微米位置和3e-5轴分量容差检查，包含原四元数舍入）。这证明模型/公式一致，仍不是实机安装计量。
- H0/H2：取自现有12参数诊断模型A与控制器K。H0在S中约[-284.825,-3.585,-86.560]mm，H2在yaw0/pitch-25时约[-20.169,-0.487,496.148]mm。H0到H2的640mm与控制器首段D一致，H0不必位于头壳；其拟合yaw轴偏离躯干+Z约24.428°，尚不能作为已验证真实机械轴。
- C_L/C_R：整体安装来自同一诊断模型B，不能确认光心在实机上的位置。两眼相对变换取自真实双目标定，光心间距59.538mm，方向和基线符号闭环正确。C是校正后的光学系。
- 旧图的文字旁白点是标签锚点，不是坐标原点；XYZ文字位于设定轴端，但原箭头与模型叠加时难以看清轴段，造成脱节感。这属于显示歧义，不改变变换矩阵。
