# 相机重标定后的重采计划

目标：在明确的可见工作空间、头姿范围和停稳/运动条件下，同一目标点的躯干系视觉位置与冻结FK参考的欧氏距离小于1 mm。P95小于1 mm只能作为阶段指标；最终同时报告最大误差、超限率、拒绝率和各子组结果。有限采样不能证明未覆盖的全机械范围。

## 哪些必须重采，哪些可以保留

- 本轮新验收应全部使用新相机版本下的新采集数据；旧四姿留作历史对照，不与新版本混合拟合。
- 新相机参数改变三角化与校正像素域，旧相机XYZ、校正像素、手眼模型与RBF权重不能直接复用。只有保留原始左右图、完整关节/时间/安装元数据且物理配置未变的旧数据，才可能完整重处理作研究对照，仍不能替代新会话验收。
- MDH、躯干到机械臂固定变换、头角顺序不因相机重标定自动改变；冻结其版本。球/夹具未动时可复核原pF，移动、换球或换夹具后需重新测量/标定。
- 原示教轨迹可以保留为位置计划，现场复核可见性、碰撞与限位后使用；重新记录实际关节反馈及图像，不能把旧FK记录直接贴到新图像上。

## 采集顺序与建议起始规模

数量是实验起点，不保证达标；先做预实验，检查重复性、可辨识性和覆盖，再扩采。

|顺序|数据集|建议规模与覆盖|用途|
|---|---|---|---|
|1|相机训练棋盘格|30–50对，双目共同视场的中央/边缘、近中远、不同倾角；板和相机停稳|拟合K/D/R/T与校正矩阵|
|2|相机独立验证棋盘格|另采15–20对，位置和板姿与训练不同|冻结参数后检查极线、三维格长及板形；不能用这批调参后仍叫独立验收|
|3|固定姿态重复性|5–10个空间点，至少3个头姿；每次50个原始帧对，记录实际时长|分离视觉噪声、漂移与融合收益；同时报告单帧及实际运行融合窗口|
|4|头部往返/回差|固定臂，多个目标点；每个测试头姿分别从正反yaw/pitch方向接近，每方向至少5次停稳返回|量化方向偏差与A→B→C→A重复性|
|5|躯干固定靶与头链|刚性固定靶，多yaw×多pitch交叉观察，保存靶角点/点ID|先排查相对头部运动；需物理S坐标锚定时测量靶相对S的位置，不把名义值当测量|
|6|动态手眼训练（先停稳）|每臂30–50个物理球位×15个交叉头姿，每组合50帧；球位覆盖XYZ、图像边缘与不同法兰朝向|拟合有效头链、球偏移及必要残差；不是仅采一条近平面轨迹|
|7|独立最终验收|另日/重启的新会话，未见头角＋15–20个新球位/臂，并含新的臂构型；复测训练角度及边界|验证跨角度、跨空间、跨构型和跨会话泛化|
|8|运动专项（若目标包括运动中）|覆盖实际要求的速度/方向/加减速与曝光条件，独立训练/验收轨迹|验证曝光-反馈时钟、双眼异步、读出和运动模糊影响|

相机训练与相机验证完成后，先冻结校正流与测量分辨率，再采3–8，避免中途更换相机参数。

## 头角设计

第一轮用项目现有9姿预实验：yaw ∈ {−10,0,+10}°，pitch ∈ {−25,−20,−15}°，全交叉。可以先用12个已示教点检查可见性和记录链路。

扩展训练建议：yaw ∈ {−20,−10,0,+10,+20}°，pitch ∈ {−25,−15,−5}°，15个全交叉头姿。所有角度须由现场确认限位、碰撞与目标双眼可见性；本文件不下发运动命令。该区域只是首期工作范围，不等于“全部头姿”。

预留未见角度示例：yaw ∈ {−15,−5,+5,+15}°，pitch ∈ {−20,−10}°，8个交叉测试姿。最终会话另复测训练网格边界。测试角度和球位在采集前固定，不根据误差更换。若扩大工作域，需要重新覆盖相应范围。

同一物理球位尽量采完整头姿矩阵，避免“某一空间区只在某一头姿出现”。同时正反序或随机化头姿顺序，以免头角与温漂、时间、接近路径绑定。50帧属于一个组合的重复观测，不能当50个独立球位拆到训练和测试。

## 每次观测必须保存

- 原始左右图/可追溯无损帧、左右帧ID、传感器标识、原始分辨率/裁剪/曝光/增益；保留检测失败与拒绝原因。
- 原始像素域、校正参数版本和哈希、校正分辨率、四维同名点像素；球目标另存椭圆拟合、球径、球心投影修正及其版本，不仅保存融合XYZ。
- 实际头yaw/pitch反馈、反馈时刻、速度与停稳窗口；实际臂q7、臂侧、躯干关节/基座状态和FK配置版本。角度顺序/单位显式记录。
- 逐眼时间戳及其语义（曝光、驱动还是接收）、clock_id、同步/映射证据；运动数据还需曝光附近连续头/臂反馈历史，不能以网络到达时间冒充曝光时间。
- session_id、physical_point_id、头姿ID、重复编号、接近方向、采集顺序、日期/启动状态、球/夹具ID、pF测量或训练估计来源。
- 稳定窗口的每帧结果与实际融合规则；融合后误差不能代表单帧误差。

新相机 JSON 的哈希、MDH/S←M、pF、目标定义和运行图像处理配置应写入会话清单，整个会话保持一致。

## FK参考与分组规则

冻结指定FK后，视觉输出仅用像素与头角；臂q7/pF只用于标签。若能用固定基准约束同一真实球心，应以多个臂构型测试该点的FK一致性。若同一点的两个FK标签相距超过2 mm，就不存在一个视觉位置能同时严格落在两者1 mm范围内；此时需要处理FK/夹具问题。

训练内按物理点、空间块、臂构型和头姿分组选择模型。相同点的所有重复帧、所有头姿以及跨会话重采记录保持物理点绑定；不能随机按帧切分。最终验收另留新点、新头姿、新会话；固定已训练的pF和FK，不能用测试数据重估标签。左右臂各有pF、S←M和独立结果，不以右臂结果代替左臂。

报告三维欧氏误差的均值/RMS/P95/最大值及≥1 mm比例，并按头姿、空间、构型、方向、会话、臂侧分组。质量拒绝规则事先冻结，报告总体有效率，不能事后按FK误差筛点。相机板形合格、软件合成测试通过均不等于最终视觉/FK达标。
