# 固定根旋转约束为Ry(q1)的重新拟合

## 精确定义

按用户公式字面解释：q1是实际反馈俯仰角；只把A的旋转块替换成Ry(q1)，保留A的平移tA和后续原Yaw→Pitch链。

`p0=tA + Ry(q1) Rz(q0) Ry(-q1) (RX pC + tX)`

没有把整个A替换成纯旋转而删除平移。q1使用档案反馈，不是待拟合常数。旧版Luna、原始日志、控制器、默认运行模型均未改动。

另作两个明确区分的对照：固定RA=Ry(+25°)；以及RA=Ry(beta)，beta为独立的固定安装角待拟合。二者都保留原Rz(q0)Ry(-q1)，不把beta作为反馈角。

## 数据、标签及划分

1202条有效四姿数据，按四像素重新三角化。复用fk_consistent_vision_20261026/results.json的相同球位划分和每折训练侧pF；通过来源/配置哈希及训练/测试数核对。每个模型面对相同冻结的FK参考，不通过改变pF/MDH降低自身误差。

主划分996训练观测/206测试观测，对应256/65球位。训练冻结有效pF `[-3.053776,5.007027,101.571564] mm`。参数表与保存的train_model均来自996条训练观测，不把1202条全量拟合误差当留出误差。

## 一个结构性问题与一个参数规范

yaw=0时，Ry(q1)Rz(0)Ry(-q1)=I，故模型预测变成tA+RX*pC+tX，对反馈pitch不再有任何响应。固定机械臂、只从[0,-25]转到[0,-20]时，真实相机坐标会变化，但模型没有相应俯仰变换。这是该代入在当前完整公式下的结构性问题，不是优化没收敛。

此外，档案所有非零yaw的pitch都是-25°，该约束链退化为绕固定n=Ry(-25°)*ez转动；其余yaw0时为I。沿n同时令tA+=d*n、tX-=d*n，预测不变。于是9个自由参数(tA3+X6)只有秩8，参数不能唯一列出。

本实验明确固定tA_z=498.98mm作为规范选择，只优化tA_x/y+X6共8参数。固定值不是新测量。自检验证了完整9参数秩8、规范后的8参数恢复，以及yaw零位的pitch抵消。固定beta对照不施加此tA_z约束，因为其主训练集Jacobian满秩。

## 结论

将RA设为随反馈变化的Ry(q1)，在保留其余原公式时不适合当前数据；结构上取消了yaw零位的俯仰响应，纯几何及补偿后误差均显著变大。

若用户希望“把之前约+25°的安装旋转简化为纯Y轴旋转”，应该写RA=Ry(beta)，beta是固定安装角，不是实测关节角q1。本轮单Y轴约束重新拟合beta约+25.0227°，而此前完整三轴A旋转向量Y分量约24.8528°；约束和优化参数不同，数值小幅变化正常。不能据此把记录的q1=-25°改成+25°。

拟合量均为相对于当前冻结FK参考的有效参数，非实机安装测量。全部模型approved=false，尚未达到任意头姿P95<1mm。

20项离线测试通过；新增抵消、规范自由度与合成恢复测试。没有操作硬件、修改名义参数或替换默认运行模型。
