# 为什么Pro固定头姿约1mm多，而Luna固定头姿更差

2026-10-29。核对Pro原报告，并对原始归档和Luna数据追加固定pF的静态对照。未修改任何相机、机器人、pF或实机采集参数。

## Pro的1mm多是什么

`head_eye_pro/reports/shared_pf_joint_kernel_20261021/report.md`中的最终实验候选为每臂仿射＋共享pF＋相机系共享高斯场：右臂RMS0.887mm/P951.611mm，左臂RMS0.841mm/P951.484mm。它有两臂各12个仿射参数、3个共享pF参数，以及正则化核系数。共享pF拟合为[0.805,0.251,100.582]mm，属于拟合量。该候选不是单一六参数刚体，也不是全部位置误差都在1mm内；报告说明默认vision_deploy参数未由该候选替换。

但Pro并非完全靠复杂补偿获得低误差。其右288点批次纯刚体＋自由pF已有训练P951.569mm、5折留出P951.678mm；跨会话旧→新P951.895mm、新→旧P952.339mm。独立会话会变差，仍明显优于本轮Luna静态纯刚体约5mm。

上一答给Luna的5.012mm是固定精密pF、六参数刚体的同批训练残差。把它直接与Pro最终补偿后的留出值比较，模型和验证口径均不同。本报告补齐相同静态方法的诊断，不能据此抹去数据本身的差距。

## 新做的静态对照

对四组数据都固定pF=[0,0,101]mm；Luna保持用户精密测量值，Pro采用同值仅作为敏感性假设，不是认定Pro实际工具偏置也是该值。各自使用自己的MDH和观测，不能混用机器人模型。Pro归档解压SHA及MDH哈希核验，存档法兰位姿与重算MDH一致；Luna复用现有严格导入器。

每组按原始轨迹顺序排列有效位置，5折连续分段，训练剔除留出块两侧各2个有效邻点。每位置50帧保持整体；不按残差筛点。评估纯刚体、仿射、相机系联合仿射＋高斯三个方法。

联合高斯使用Pro的固定pF、单臂特例：核长60mm、alpha3，在相机域联合估计仿射与场，再逆仿射输出目标点。pF已固定后该问题为线性变量投影，可直接求解，无需额外优化库。它复现的是Pro算法的受限特例，不是其双臂共享自由pF完整算法。所有训练/验证折均通过Pro的0.9–1.1奇异值及仿射相对初值±0.03元素范围检查。

|Pro右臂，固定101诊断|288|1.796|1.697|1.688|

重要反例：Luna B的联合高斯训练P95为0.985mm，但留出为2.711mm；新轨迹该方法训练为4.676mm，留出为5.734mm。只报告训练误差可以制造“已进1mm”的印象。本轮新轨迹的非刚体方法没有改善留出，故没有部署该模型。

## 能排除哪些简单解释

1. **不能只归因于动态头链。** 所有Luna对照均固定[0,-25]，相机直接对齐FK点，不使用动态头部运动学。差距在这个特例中仍存在。
2. **不能归因于把输出改成躯干系。** 若对视觉与FK同时应用同一刚体变换，欧氏误差不变；而固定头姿单独拟合的自由外参还能吸收固定的躯干→臂安装刚体差异。它无法吸收随关节构型变化的FK偏差或相机非刚体测量误差。
3. **不能只归因于固定pF。** Pro把自由pF改为固定101后，纯刚体留出P95由原报告1.678变为本次1.796mm，变化约0.118mm，远小于与Luna的差距。该数值只描述Pro这批数据的条件敏感性；Luna的精密pF不应重新放开来吸收其他误差。
4. **不是Luna观察更远或像素规格明显更差。** Pro相机f约398px、B约59.74mm，本项目约400px、60.48mm。Pro深度0.286–0.616m，本轮Luna约0.194–0.544m。Luna并未因更远距离天然承受数倍深度放大；实际相机标定质量和检测系统偏差仍可能不同。
5. **不能从拒绝率直接推导标定精度。** Pro右288批原360位置有72个拒绝，拒绝率20%；本轮Luna202位置拒绝43个，约21.3%。拒绝比例相近并不保证合格点无偏，也不足以解释两者残差差异。

## 最可能的解释与优先验证

现有证据说明：Luna的视觉球心点云与其名义FK标签之间，存在比Marvin Pro更强的空间/构型相关不一致。没有独立真值，暂不能把全部不一致确定归为机械臂MDH或双目误差。

- **机器人与FK模型不同。** Pro用1004.ini，Luna用luna_new.ini。右臂L2.D、L4.D分别为Pro287/314mm、Luna264/264mm；法兰D分别95/87mm。这些是各自MDH表中的轴向偏置，不可互相复制，也不代表参数差本身就是错误。需检查实机几何/零位/MDH法兰定义与该模型的符合程度，而不只是软件是否读到同一张控制器表。
- **机械臂构型相关残差更强或不同。** 同一真实球心可由不同腕/肘构型到达；若名义FK发生构型相关漂移，纯相机空间场不能稳定补偿。轨迹B可以被局部平滑较好解释，本轮复杂轨迹则没有同样收益，提示不能将某一局部低误差推广到所有构型。该差异不是单独的因果证明。
- **双目共同度量误差或轮廓球心偏差仍需排除。** 跨头姿点云彼此刚体一致，也可能共同带有尺度或视场偏差。冻结曝光、低纵差、50帧低抖动均不能证明绝对三维无偏。普通目标也未必继承标定球的检测误差特征。
- **数据支持与协议不同。** Pro报告以固定相机、固定会话和较密支持区为主；本项目多轨迹、不同球位和身体条件更容易暴露分布变化。即使方法相同，换一台机器人也不会继承上一台的残差规律。

优先顺序：固定球心、改变臂构型检查FK漂移；精密已知间距靶在中心/边缘及近中远位置检查双目尺度；同一固定头姿、同一路径正反回放检查回程差与时间漂移。条件独立约束后，再考虑校准可辨识的关节零位、实际轴线和残余空间场。

因此“直接采用Pro最终算法就能回到1mm多”目前没有证据支持；本次单臂固定pF特例已显示其对Luna新轨迹无稳定改善。下一步应优先定位并修正物理/参考不一致，保留严格留出验证。
