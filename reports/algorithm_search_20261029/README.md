## 误差原因与方法

B的相机跨头姿刚体一致性约0.44–1.02mm，但相对FK误差达9.54mm。B中62.9%的观测离原RBF中心超过50mm、23.6%超过100mm。主要问题包括空间外推、FK/法兰/相机度量的共同系统误差，以及约1–3mm的头链跨姿余差。

原方法先用FK标签拟合头链，再只学习局部高斯残差。FK误差可能进入头链，远离核中心时补偿趋近零。新路线：

1. 对同球位多头姿观测优化相机固定安装X，使`K(q)X*p_C`尽量落在同组均值；此阶段不使用FK标签。Yaw→Pitch不变。全局头根自由度由名义根选择，仅作计算坐标规范。
2. 全局仿射趋势和高斯场共同对齐冻结FK：`p=p0+F(p0)B+K(p0,P_train)W`。固定核后用变量投影同时解趋势与场系数，仿射趋势在核支持之外仍可保留全局校正。

最终输入仅校正双目四像素和实测头角，不输入q7、pF或轨迹编号。仿射项及空间场是经验映射，不能解释为真实安装测量或新相机内参。

## 验证定义

- A→B/B→A两个完整轨迹留出；5个按FK位置主跨度划分的空间块；5个按关节主成分划分的构型块；4个完整头姿留出，共16折。同一轨迹同一球位的全部头姿整体入空间/构型折。
- 两种头链估计（FK驱动/相机相对），结合几何、原两阶段RBF、仿射、二次趋势和联合趋势/高斯场，共44候选。
- 核中心与系数仅取训练折。最优指本轮列明候选和验证规则内，不是所有可能算法的全局最优。
- 无外部参考，不能唯一分离真实MDH、法兰坐标、球心投影、双目度量尺度或结构挠曲误差。

## 下一步数据

1. 已知间距靶：10–20个中心/边缘、近中远位置，保留原始双目图和50帧测量，检验尺度及视场偏差。
2. 固定球心夹具：3–5个位置，各10–20种法兰/肘部姿态，检验固定精密pF下的FK一致性。
3. 完整9姿开发网格：yaw=-10/0/+10、pitch=-25/-20/-15，另教120–180点覆盖不同空间与构型的轨迹。
4. 模型冻结后新轨迹C：已见四姿的新球位，并预留[-5,-22.5]、[5,-22.5]、[-5,-17.5]、[5,-17.5]。未补齐训练边界前，后者暂含局部外推，不能声称全范围通过。
