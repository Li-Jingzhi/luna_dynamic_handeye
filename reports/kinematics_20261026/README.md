# 当前算法、数据与运动学参数图（2026-10-26）

图：`luna_v2_stereo_dual_arm_parameters.png`。根据本地控制器MDH、双目配置与名义安装矩阵生成。源脚本`draw_parameters.py`使用可选Pillow，仅用于生成报告，不是运行时依赖。

## 算法

当前采用球心点对应的两端刚体动态标定：`p_MR = A K(qh) X p_CL`。K是旧V2.0控制器Yaw→Pitch MDH。优化变量是A=右臂父系←头部MDH根系和X=头部两关节末端←校正左眼，各6自由度，使用旋转向量与米制平移。不是固定头姿逐姿配准，也不是直接调用OpenCV棋盘格AX=XB接口。

先用多旋转初值搜索X，固定X时以Kabsch/SVD消去A；再将两矩阵共12参数联合进行Huber阻尼最小二乘，Huber作用于各XYZ标量残差，阈值3mm。最后检查12列雅可比秩和收敛梯度。MDH、球偏置、编码器零偏、内参及双目相对外参固定。

推理输出：`p_S = T_S_MR A K(qh) X p_CL`。两眼的相对位姿与头部整体安装外参不同：已知双目外参只约束两眼之间的关系，不提供头部到相机的X。

## 数据分别用于什么

| 数据 | 文件 | 用途 |
|---|---|---|
| 原始双目鱼眼、校正参数 | configs/camera/luna_raw_fisheye_stereo.json 与 luna_rectified_stereo.json | 去畸变/校正、球心三角化；此次不重新标定 |
| 双臂与头部MDH | configs/robot/luna_new.ini | q7到法兰FK；实测yaw/pitch到头部变换K |
| 躯干到双臂固定安装 | configs/robot/torso_mounts.json | 左右臂参考点转换和最终躯干输出 |
| 右法兰球心偏置 | configs/robot/ball_offset.json | 用[0,0,0.101]m把右法兰位姿变为参考球心 |
| 实机对应点记录 | datasets/raw/ball_point_head_20261018_v1.jsonl | 相机球心、校正像素、q7、头角、躯干反馈与观测质量字段 |
| 拟合结果与验证 | reports/luna_v2_20261026/model.json、validation.json | A/X及分组误差；approved=false |

实机记录969条，884有效、85剔除，311个球位组；头姿仅[-10,-25]、[0,-20]、[10,-25]度，单会话、仅右臂。每条有效融合记录要求至少50个有效帧，但历史日志缺少完整逐帧停稳证据，不能把它当连续运动数据。

现有标定相机参数来自37对有效标定图的结果文件；本轮未重新读取或重跑这些标定图。三角化球心是已经按球心投影契约修正的球心，不是直接把黄色椭圆中心当作三维球心。

训练三维误差P95=5.250mm，轨迹分组留出P95=3.388mm。整头姿留出因剩余头角缺少二维激励无法拟合，单会话也无法做跨会话验证。双臂联合接口与合成测试已实现，但真实拟合没有左臂样本；左法兰球心偏置须另行实测。
