# 自由pF：当前Luna数据的方案比较

日期2026-10-26。离线研究，未修改当前六参数运行模型或实测pF文件。结论只限于本轮候选和历史数据，不能认作全局最优或新实机验收。

## 结论

按训练集分块验证优先选择：**一个共享有效pF＋每头姿独立刚体＋共享/头姿独立加性RBF**，核长度20mm、ridge=1。训练选择区拟合pF=[-3.117185,4.997733,101.617584]mm，相对实测[0,0,101]mm相差5.922mm；这只是数值一致性的有效偏置，不证明真实球心偏心。

| 方法 | 历史留出P95 mm | 训练CV最差P95 mm |
|---|---:|---:|
| 当前统一混合头链＋自由pF（9参数） | 7.940 | 23.816 |
| 自由pF＋每头姿独立刚体 | 2.747 | 见comparison.json |
| 自由pF＋每头姿独立刚体＋加性RBF20mm/1（选中） | 1.831 | 2.564 |
| 自由pF＋每头姿独立刚体＋独立RBF20mm/0.1 | 1.744 | 2.775 |

1.744mm是本批历史留出的最低分，但它的训练CV最差块高于选中方案，不满足本轮优先最差块的选型规则；不能看过留出结果后反过来称它是无偏选出的最佳。训练CV选择的加性方案15折P95平均2.193mm、最差2.564mm，亦为严格minimax赢家。

加性方案留出161条：mean=0.747mm、RMS=0.921mm、P95=1.831mm、max=2.676mm。仍未达到P95<1mm。

## 数据与划分

沿用当前项目原始969条中884条有效观测、311球位组、3个已见头姿，只有右臂、单会话。前248组/723观测用于训练与选择，后63组/161观测作为历史尾段留出。同一个球位的全部有效头姿不跨折。不同于head_2dof_capt历史只取274完整球位/822观测，本轮不排除部分头姿无效的球位。

训练区内部做5折轨迹、5折空间、5折构型验证。空间折按法兰位置跨度最大的轴排序；构型折按q7主成分排序。每折重新估计pF与各头姿刚体，只从训练样本取RBF中心，不读取验证FK残差学习权重。空间/构型划分算法是本轮定义，不声称与原项目历史折完全相同。

## 自由pF与独立刚体

每个观测的参考球心为`b_i(pF)=t_Fi + R_Fi pF`。一个共同球/连接件使用同一个pF，而不是每头姿各自改变球偏置。每个头姿有自己的相机←右臂MDH刚体`C_h`：

`min_(pF,C_h) sum_i ||C_h b_i(pF)-p_Ci||^2`。

复用head_2dof_capt/interactive_ball_calibration/validate_pf_rt.py的fit_model：对每个候选pF以Kabsch精确消去各头姿C_h，三参数变量投影更新pF。检查法兰朝向激励、投影雅可比可辨识性、收敛和pF模长不超过200mm。训练区投影雅可比条件数2.084；15个训练折的pF约X[-3.322,-2.880]、Y[4.725,5.276]、Z[101.358,101.883]mm。

基础模型共有3×6+3=21个几何变量。不是动态六参数模型，也不能把优化后的pF当作外部计量真值。

## RBF比较

在训练折内先拟合上述pF/刚体，得到初始机器人位置B_h(p_C)，再拟合FK球心与B的残差。比较27个补偿候选：shared/per_head/additive，长度20/50/100mm，ridge=0.1/1/10，加纯刚体共28种。

- shared：在预测机器人位置B上学习共用RBF。
- per_head：在相机XYZ上学习各头姿独立RBF。
- additive：K_shared(B,B') + 1[h=h'] K_local(p_C,p_C')。

`W=(K+ridge I)^-1 (target-B)`。这是**先pF/刚体，再残差**的两阶段优化，没有对每种补偿重新联合估计pF，更不是Marvin的联合仿射/pF/高斯场算法。候选之间使用相同训练折pF，避免通过改变标签制造RBF比较收益。

只用训练15折最差块P95选minimax，再在其5%容差内选平均分块P95最小者；末段留出不参与选择。本轮选中与严格minimax一致。

选中训练模型保存于selected_train_model.json，包含723个训练中心和2169个正则系数，approved=false。predict_selected的离线数学验证仅输入相机点与离散头姿，不读取q7或pF；预测数学可不依赖pF，不代表已经完成运行入口、支持域或发布验收。

## 统一混合头链额外释放pF

另拟合`F_fixed Rz(yaw) Ry(-pitch) X p_C = FK_ball(q7,pF)`，固定几何不改，仅优化X六参数和pF三参数，保留Huber损失。尾段留出P95=7.940mm；有效pF约[-4.783,6.348,107.180]mm，9列雅可比满秩。15个训练块平均P95=13.614mm、最差23.816mm。说明单纯释放pF不足以闭合当前统一头部几何与数据。

## 使用范围与比较限制

选中1.831mm方案只支持[-10,-25]、[0,-20]、[10,-25]三个已观测停稳头姿；没有未见头姿、连续运动或新会话精度。不能用离散头姿查表代替连续运动学，也不能承诺全工作区。

本轮自由pF改变了FK球心标签，所以不能把与固定pF基线的误差差值全部解释为视觉精度改善。仅右臂数据不能证明左右臂共享pF有效。若机械测量确实确认X/Y=0，应优先核查偏置与法兰坐标定义、相机及FK误差，不应直接以5.922mm的有效修正覆盖测量结果。

本批数据及历史尾段已被多轮查看；这里的CV隔离避免本轮折内泄漏，不消除历史研究偏差。仍需新会话、不同构型和未见头姿验收。
