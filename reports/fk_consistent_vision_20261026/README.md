# 面向FK一致性的动态双目映射：不把头部URDF当作真值

## 目标与参考定义

最终输入为校正后的同名点 `[uL,vL,uR,vR]` 与实际头部反馈 `[yaw,pitch]`，最终输出为躯干参考S_MODEL中的三维位置。机械臂q7和黄球pF只在训练/验证侧形成参考标签，不进入位置预测。

本报告固定现有右臂MDH及S←M变换为“需要对齐的FK版本”，没有宣称它们物理准确。S←M仍来自名义安装配置；若实际躯干坐标需要锚定机械基准，须独立测量该固定关系。没有外部坐标锚点，视觉/机器人联合标定存在整体刚体坐标自由度，无法仅凭现有球记录证明物理S原点与轴准确。

若目标只是与指定FK一致，无需先估计真实MDH；应冻结FK版本、让视觉映射对齐它。若需要真实机器人位置准确，则须另外校准机器人几何，重新冻结新FK版本，再标定视觉。两者是不同验收目标。

## 本次公平比较

- 原有1202有效观测、321物理球位、四头姿。匹配球位核对相同q7，跨会话合并绑定，训练/测试球位不泄漏；整头姿留出允许其他头姿使用同球位，双留出同时排除球位。
- 每个外层折只在训练数据上，用独立每头姿刚体配准的变量投影估计共享pF，不使用头URDF。随后冻结pF；所有候选使用完全相同的FK标签，验证数据不参与估计pF。
- 主球位训练pF约 `[-3.054,5.007,101.572] mm`。各外层折独立估计，均为有效偏置，非独立实测尺寸。
- 所有训练和测试点均从档案四维像素重新三角化，遵守相机坐标、像素范围、极线、正深度与重投影检查。重建结果与原档案融合XYZ差异P95 0.0538mm，最大0.1349mm。
- 比较15种预设模型/组合；空间RBF固定50mm/ridge1，条件核固定100mm/5°/ridge0.1。没有按测试点调超参数。但候选设计参考过旧测试结果，本次属于探索性比较，不能作为新的独立验收。

## 实机结构确认与拓扑对照

用户于本轮明确确认：2026-10-18两份数据由旧版Luna V2.0采集，实机顺序Yaw→Pitch。原始日志本身没有robot_version字段；保留原文件不改写，本报告以用户确认作为版本依据。运行顺序不改为Pitch→Yaw。

新增Pitch→Yaw固定6参数及其躯干核仅为离线结构对照，不是推荐部署模型。它在整头姿两端P95也可得到2.589/2.590mm，加躯干核为2.203/2.427mm；这些低分不能推翻已确认实机顺序。

原因是四头姿布局存在精确的结构混淆：所有非零yaw都在pitch=-25°，其他pitch只在yaw=0。令B=Ry(25°)，则在这四个头姿上，`Ry(-pitch)Rz(yaw) = B Rz(yaw)Ry(-pitch) B^-1`。两端自由的Yaw→Pitch链可以吸收这个常量B；在非零yaw且pitch≠-25°时两者一般不同。自检已验证四姿上的相等与[10,-15]处的分歧。

有效链12拟合头根相对名义值约绕Y倾斜24.85°，接近25°。在已确认Yaw→Pitch的前提下，这只能解释为有效映射的诊断线索，可能包含参考系/安装/其他系统误差，不能认定实机yaw轴倾斜或擅自交换关节顺序。应以交叉头姿及独立坐标基准排查。

## 模型与参数

### 固定名义几何6参数（基线）

`T_S_C(q)=F_URDF Rz(yaw) Ry(-pitch) X`，固定根安装，只拟合X6。条件核补偿输出位置误差。该条件核使用新冻结pF标签重新拟合，与旧报告2.852mm等不属于完全相同训练目标，不能把跨报告差值全归因于算法。

### 有效运动链12参数

`T_S_C(q)=A_eff Rz(yaw) Ry(-pitch) X_eff`，拟合A6+X6。URDF仅用于初始化，不固定安装偏置/姿态，不用D=640mm。它仍假定两轴正交且相交。

增加的6参数用于拟合原先被当作已知量的头根安装；黄球pF3在前置训练阶段估计、随后固定。因此完整标定含pF时为15个有限维参数，运行推理不需要pF。A_eff/X_eff是对选定FK参考有效的参数，不能仅凭误差下降把它们认作真实机械安装测量。

### 一般双转轴POE14参数

`T_S_C(q)=exp(S_yaw*yaw) exp(S_pitch*(pitch+25°)) T_ref`。每条转轴方向2参数、位置2参数，两轴共8；参考相机安装6，共14；另有训练侧pF3。允许两轴不正交、不相交，不依赖某张DH/URDF表的准确性。参考位姿取yaw=0,pitch=-25°，避免无必要的零位偏置重复参数。

轴方向参数以近+Z和近−Y的局部图表示；轴上点分别固定在相对名义中心z=0/y=0平面以去掉轴向平移规范自由度。轴位置/方向使用明确的弱正则先验（方向参数尺度0.35、位置0.10m），不是实测约束；数值可见模型文件。原始数据Jacobian秩不包含先验。

POE表达来源：[Modern Robotics，空间坐标系POE](https://modernrobotics.northwestern.edu/nu-gm-book-resource/4-1-1-product-of-exponentials-formula-in-the-space-frame/)。已有双臂标定研究说明，加入接触、平面等独立约束有助于改善参数可观测性，且其具体实验中分阶段标定优于全部参数同时标定；本项目仍需自己的验证：[Stepanova等](https://arxiv.org/abs/2012.07548)。

### 躯干位置残差补偿

先得到 `p0=T_S_C(q)*triangulate(pixels)`，再输出 `p=p0+g_S(p0)`。g为共享高斯空间场，核中心也是训练点的几何预测p0，**推理时不读取FK/q7/pF**。核中心尺度50mm、ridge1；每个训练样本3个输出权重，因此补偿不是“只有12或14个参数”。

对照还测试了相机点到躯干残差、相机局部坐标补偿、直接头角线性仿射回归及其空间核。相机域补偿虽降低同头姿新球位误差，却可能增大跨头姿误差；躯干位置域更适合作为本批数据的研究候选。

## 结论与建议

现有数据优先采用“学习有效运动链，再在躯干位置上做共享残差补偿”的研究路线。纯有效链已经把两端整头姿约20mm误差降到约3mm，说明校正名义头链比直接增加头角高斯权重更有价值。空间核进一步降低两端误差。完整POE在已有充分激励折没有显示比简化12参数明显更好；不要仅因参数更多就替换为POE。未来若实测证实轴不正交/不相交，并补齐激励，可使用一般POE表达。

本报告不证明名义URDF哪一项错了：拟合A_eff相对名义根的姿态变化可能吸收头轴、相机和FK参考错误。也不把各折最好模型拼成一个模型。

目前所有候选均未实现所有测试P95<1mm，且四个稀疏头姿不能验收任意头姿。不要以拟合训练误差或单一球位留出替代整头姿、空间块、臂构型块和新会话验收。新增候选尚未重做完整空间/臂构型嵌套选型，不作最终部署结论。

### 需要补的约束

1. 冻结目标FK版本。若要升级真实MDH精度，先增加独立约束（接触、已知平面/距离、外部测量），仅优化可辨识的关节零位/连杆参数并保留先验；不要把相机内外参、所有DH、头链、双臂根与pF同时无约束放开。
2. 用躯干固定参考靶，在多个yaw和pitch交叉网格采集，先估计头部相对运动。再用相对躯干已知的参考点/机械基准锚定S，避免机械臂误差冒充头部安装误差。
3. 做同一物理点的多臂构型一致性检查。若真实位置相同，而所选FK在不同构型给出的球位置不同，则单一只依赖像素/头角的函数不可能同时匹配两种FK标签；必须校准FK或明确一致性容差。视觉不能在推理时加入q7来掩盖这个矛盾。
4. 采集yaw至少−20/−10/0/+10/+20、pitch至少−25/−15/−5的交叉覆盖；正反方向到位、重复会话、新空间球位验收。这个网格只验证覆盖区域，不能推及全机械限位。
5. 新增左臂数据并独立确认左侧pF与S←M_L。现有实测结果仅右臂，不能声明双臂均已通过。

## 使用与复现

`OPENBLAS_NUM_THREADS=1 .venv/bin/python reports/fk_consistent_vision_20261026/analyze.py`

四维像素研究接口：

```python
import json
from pathlib import Path
from dynamic_handeye.geometry import Assets
from reports.fk_consistent_vision_20261026.analyze import predict_pixels

model=json.loads(Path('reports/fk_consistent_vision_20261026/learned12_torso_rbf_train_model.json').read_text())
# pixels是ideal_pinhole同名点四像素；qh是反馈yaw/pitch度数。
xyz_s=predict_pixels(model,Assets(),pixels,qh,diagnostic=True)
```

普通目标不需要球半径或pF；输入必须为同一三维点的左右像素。黄球档案已完成球心投影修正，不能把其专用修正无条件套给普通目标；相机域系统误差与普通目标的迁移仍须独立测试。

模型均approved=false，predict_pixels默认拒绝非诊断运行；不替换正式运行入口。模型附来源/配置哈希，不接受换FK配置后继续复用。原始采集与名义MDH/URDF均未修改。未连接硬件，未重新检验运动曝光同步。

19项测试通过，144份复制源文件哈希核验通过。新增自检覆盖：关节顺序在现有四姿上的结构混淆反例、配置变更拒绝、有效12参数恢复、非正交且分离转轴POE的未见角预测、四像素接口三角化/坐标变换、物理角度边界和未批准模型拒绝。详情、各折pF、数值秩和优化收敛指标见results.json。
