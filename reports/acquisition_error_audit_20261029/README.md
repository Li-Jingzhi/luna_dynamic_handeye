# 采集链还是其他地方：逐层证据审计

2026-10-29。主要新线索：在三批固定头姿数据中，受约束的机械臂关节零位修正能显著降低相机—FK闭环残差，跨轨迹转移也成立。相较普通采集抖动、帧重复、整位置错配，名义FK系统误差更值得优先核验；但无外部真值仍不能排除相机共同偏差被零位参数吸收。

Pro右288点的单点三维P95抖动中位数0.332mm，比这三批Luna更大，但固定101诊断刚体拟合P95仅1.753mm。因此Luna的较大残差不能主要用随机检测抖动解释。

## 校正实现实测

直接在当前Orin上生成正式VPI鱼眼校正映射，与同K/D/R/P、1280×992输入的OpenCV映射逐像素比较，无需打开第二个相机或中断推流：

- 左：映射坐标差中位0.0000305px、P950.0000863px、最大0.0001365px。
- 右：中位0.0000381px、P950.0001221px、最大0.0001365px。
- 若错误改用R转置，则左中位差27.55px、右16.96px。

所以没有发现当前VPI实现的校正旋转方向错误。该检查验证两种实现等价，不验证相机内外参对真实光线足够准确。接口依据[NVIDIA VPI鱼眼映射文档](https://docs.nvidia.com/vpi/3.2/python/build/vpi.WarpMap.html)。原始棋盘与正式测量链都使用相同sensor-mode0，未见额外180度翻转；正式测量在1280×992执行，预览640×496不参与测量。

已核对源配置哈希、球心投影修正代码、逐帧三维与像素使用，未发现把已修正像素再次当椭圆中心进行重复修正的路径。当前缺原始图像证据，不能据此排除轮廓拟合偏差和相机度量偏差。

## 不依赖外参的形状不一致

比较任意两个位置的相机距离与FK距离，刚体变换无法改变这些距离：

|数据|两两距离差P95，mm|最大，mm|
|---|---:|---:|
|Pro固定101诊断|1.770|4.533|
|Luna A|8.115|12.723|
|Luna B|5.978|8.247|
|Luna新轨迹|5.886|14.256|

说明更换外参求解器、调整固定躯干安装平移不能消除全部误差。新轨迹最大距离差14.256mm意味着任何刚体配准至少有一个位置误差≥7.128mm。这是几何下界，不说明到底是相机形状还是FK形状不准。

## 关节零位假设实验：最有力的新线索

固定pF=[0,0,101]mm，MDH长度和相机内外参不变。仅拟合相机刚体外参和右臂J2–J7六个有效零位修正：每轴范围±2°，0.5°尺度先验正则，固定J1为0以消除与基座旋转的规范自由度。用现有Huber优化器。此实验显式改变了FK标签，因此只能叫“校正FK后的闭环诊断”，不能叫“视觉对原FK精度提高”。未向机器人写入任何零位或模型修改。

## 跨轨迹检查

把来源轨迹拟合的零位固定，在另一条轨迹不再优化零位；由于实际固定相机姿态可能不同，目标轨迹仍重新估计相机刚体外参，以5折目标位置留出评估：

|来源零位 → 目标轨迹|目标刚体外参5折留出P95，mm|
|---|---:|
|A → B|0.808|
|A → 新轨迹|1.332|
|B → A|1.359|
|B → 新轨迹|1.785|
|新轨迹 → A|1.180|
|新轨迹 → B|0.784|

这比每批各自拟合更支持“某种稳定的关节相关系统误差”，降低了只对一条轨迹过拟合的解释力。但每个目标相机外参仍在目标训练折内估计，所有标签都是校正后的FK，且A/B已研究过，**不是完整冻结模型的独立绝对精度验收**。

## 采集实现仍有可改进处

与Pro相比，Luna现有融合使用组合帧身份去重，采集入口没有强制首帧晚于停稳完成时刻；源帧唯一性本轮审计均通过，但代码边界可加强。Luna使用8秒取帧窗口，Pro为15秒；缺帧点会因此更易拒绝。最终关节角采用取样后的反馈，而Pro用窗口中位数，本轮最大FK差仅0.00934mm，不是主误差。

这些属于健壮性与有效率改进，不能把缺少边界检查直接说成已经发生了错配。当前九头姿实机采集仍在进行，为保持一致性本轮没有热改采集代码或更改门槛。

## 下一步建议

1. 优先核对当前实机的关节零位和FK语义：用同一组q离线对比厂家SDK FK与本项目MDH，包括法兰定义、角度单位及符号。采集进程持有SDK时不建立竞争控制连接，等本轮结束再做在线核对。
2. 用精密固定球心夹具改变肘/腕构型：比较原FK和上述有效零位假设下的球心漂移；用外部已知距离固定尺度。这能直接验证关节相关误差，避免只拿相机作为唯一真值。
3. 再检查精密已知间距靶在视场中心/边缘的双目度量，分离稳定相机偏差。当前单目40mm球尺寸诊断并不比Pro更差，且球径未独立确认，不能用它单独判定相机准确。
4. 物理验证通过后，把标定FK作为明确版本另存，保留原FK误差；再标动态相机链，并使用全新数据验收。不要将校正FK后的低残差混称成原FK目标已达标。
