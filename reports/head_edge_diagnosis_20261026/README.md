# ±10° / −25° 误差诊断与补偿消融

数据、物理球位绑定、80%轨迹训练划分与 four_head_free_pf_20261026 相同；1202观测/321球位。复用固定混合头链、X6+自由pF3几何；没有使用控制器D=640mm，也没有改变运行配置。新候选是研究补偿，不是新的物理安装标定。

## 已确认的原因与尚不能确定的原因

1. 大误差主要是整头姿留出：−10°被排除后训练yaw只有0/+10；+10°被排除后只有−10/0。两者均在训练角度凸包之外；0/−25是其余三姿边界上的插值点。相同头姿参与训练的新球位误差原来仅2.860/1.608mm，不能解释为相机转到±10就突然失效。
2. 纯几何+自由pF在整头姿留出已达20.520/20.078mm。残差核承担了跨姿态系统误差；当前固定名义轴、共中心、安装关系没有独立实测验证。可疑来源包括运动轴/中心、安装坐标映射、视觉空间偏差和臂FK误差；这些数据不能唯一判定哪项物理参数错误。
3. 高斯局部核缺少可靠外推趋势，但不是唯一原因。原嵌套选择−10折已经选45°宽角度核，仍13.583mm；+10折5°核为19.960mm。主模型5°宽度在角距10°时角度核约0.136、20°时约0.00036（仍需乘空间核）；该数值不适用于45°那一折。
4. 现有超参数内层按球位分组，通常保留全部训练头姿，优化的是已见头姿的新球位表现，没有直接优化新头姿泛化。四个头姿、仅5°pitch跨度，无法充分约束任意角度模型。留出唯一−20°后pitch方向尤其缺乏激励。
5. 第四头姿来自独立采集会话；会话与头姿混杂。自由pF是有效拟合值，不能当外部真值；曝光同步与回差也未独立排查。

## 建议

- 当前四姿内应用保留原条件RBF。仿射趋势适合下一轮研究候选：显著改善边缘外推，但0/−25变差，不能直接提升为运行默认或声称1mm达标。
- 优先验证头部名义轴方向、两轴中心/间距和实际角度对应关系。只校正有独立测量或充分激励支撑的参数；避免以多参数联合拟合掩盖不可辨识性。保持双目内外参固定，除非重投影和独立板数据支持重标定。
- 采集yaw至少−20/−10/0/+10/+20，pitch至少−25/−15/−5，并在多个yaw覆盖每个pitch；左右方向到位重复、跨会话重复同组姿态。这样±10成为内插点。该网格只验证覆盖区域，不等于全部机械限位范围。
- 在训练内增加整头姿留出选型，外层同时留出头姿、球位，最后用未参与开发的新会话验收。可比较名义几何、受约束轴误差几何、连续趋势+残差核；不能按本表逐头姿挑最小误差拼成部署方案。
