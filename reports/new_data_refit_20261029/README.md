# 2026-10-29 新相机四头姿重新标定

## 结论

当前1254条有效观测可完成重新拟合，但尚不能发布为任意头姿正式模型。按5个轨迹块、5个真实空间块和5个关节构型块，仅用这15个训练内留出选择后，当前候选为：

`有效运动链12参数 + 躯干位置RBF（长度50mm，ridge=1）`

运行输入仍然只有校正后的四维双目像素和实测`[yaw,pitch]`；机械臂q7与黄球pF只用于训练形成FK参考标签。

## 数据与参数

- 头姿及有效点数：`[0,-25]` 353、`[0,-20]` 347、`[10,-20]` 292、`[10,-25]` 262。
- 四组均使用同一360点机械臂轨迹；跨头姿同一轨迹点的q7最大差0.001°。
- 双目重投影P95为0.051–0.069px；融合三维与四像素重新三角化差异P95为0.034–0.048mm。
- 黄球偏置固定为精密测量值`pF=[0,0,101]mm`，不参与拟合，也不允许它吸收MDH或安装误差。
- 有效链12参数Jacobian秩12/12。
- `A_eff`相对名义头根的旋转向量约`[-1.741,29.556,-5.203]°`，平移约`[11.424,-3.062,-1.218]mm`。它吸收头链、相机安装和选定FK参考的综合误差，不能直接解释为真实装配偏差。
- 完整`A_eff`、`X_eff`、核中心和权重见[选中模型](selected_model.json)，全部候选与每折结果见[results.json](results.json)。

## 后续采集顺序

1. **先采独立验证轨迹B，不加入训练。** 重新拖动一条与当前360点不同的右臂轨迹，覆盖当前法兰范围并增加边界/不同肘部构型；建议120–180个停稳位置。依次在`[0,-25]`、`[0,-20]`、`[10,-25]`、`[10,-20]`采集，每位置仍为50个独立双目帧。这一步直接判断目前3–9mm空间误差是否可复现。
2. **补齐头姿二维激励。** 用轨迹B采`[-10,-25]`、`[-10,-20]`、`[-10,-15]`、`[0,-15]`、`[10,-15]`。这样从当前2×2角点扩展为yaw负向和第三个pitch层，才能继续辨识任意头姿运动链。
3. **再做真正未见头姿验收。** 另建轨迹C，在不参加拟合的`[-5,-22.5]`、`[5,-22.5]`、`[-5,-17.5]`、`[5,-17.5]`采集；这些内部插值头姿用于验收，不能反向调参。
4. **检查回差与会话重复性。** 至少对`[0,-25]`和`[10,-20]`分别从相反转动方向到位，并在重新开机后的独立会话重复轨迹B的一部分。
5. **右臂通过后再采左臂。** 先独立测量左臂法兰到黄球偏置，再使用同样头姿和独立轨迹；不能复用右臂pF。

若目标是物理世界绝对精度而不仅是“视觉等于当前FK”，还需用已知位置基准、激光跟踪仪或接触平面先校准/验证机械臂MDH与躯干安装关系；仅增加黄球轨迹不能区分视觉误差和FK误差。
