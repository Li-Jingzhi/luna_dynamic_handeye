# 连续任意头姿＋自由pF：算法实现与目标验证

目标沿用三维误差P95<1mm。本轮实现研究接口，比较4类/64个预先列明的候选。**实际数据未达到目标，不发布模型。** 不修改当前六参数生产入口、原始观测、双目/MDH配置或实测pF文件。

## 连续模型

固定文档式头部运动学：`H(q)=F_fixed Rz(yaw) Ry(-pitch)`，不使用控制器D=640mm。主几何同时估计相机X的6参数和有效pF的3参数：

`H(q_i) X p_Ci = T_S_M (t_Fi + R_Fi pF)`。

先用原六参数标定初始化，再以Huber阻尼最小二乘优化9参数；检查9列雅可比满秩、pF模长<=200mm。当前固定头中心和轴向仍为名义假设，并未自动修正。只有右臂数据，未假定双臂共享pF。

残差可选：

1. geometry：纯9参数几何。
2. spatial：相机XYZ上的高斯核岭回归。
3. conditional：空间核乘连续头角核。
4. additive：空间核＋空间核×连续头角核。

头角用[sin(yaw),sin(pitch),cos(yaw),cos(pitch)]连续嵌入，避免离散头姿ID查表；在物理限位内任意实数角度都可数学求值。补偿输出为躯干系三维残差，预测只读相机XYZ与头角，不读q7/pF；pF只生成标定阶段参考。

64候选为1个几何、9个空间核，以及27个条件核、27个加性核。空间长度20/50/100mm，角度尺度5/15/45°，ridge0.1/1/10。几何与pF先拟合，残差随后拟合，不是所有变量的联合核优化。更多核系数不应称作仅9参数模型。

## 数据及无泄漏验证

原884观测、311球位、3头姿，单次右臂采集。尾段63球位/161观测留出，训练248球位/723观测。训练区9个分块（3轨迹、3空间、3构型）选型：最小最差块5%容差内取最小平均P95。每折重新拟合pF/X、核中心与系数；同球位全部头姿整体入折。

额外做两种外层测试：

- 整头姿留出：只用另两个头姿训练。
- 整头姿＋新球位同时留出：训练既不包含测试头姿，也不包含尾段测试球位。

每个外层测试的超参数通过**其外层训练数据内部**的3折分组轨迹验证重新选出，没有沿用含测试头姿数据选出的参数。训练和验证FK标签使用对应训练折估计的pF；释放pF改变了球心标签，不代表外部物理真值精度提高。

## 实机离线结果（P95，mm）

| 算法 | 尾段球位留出 | 整头姿留出范围 | 头姿＋球位双留出范围 |
|---|---:|---:|---:|
| 固定混合几何＋X/pF | 7.940 | 13.648–24.526 | 7.018–14.391 |
| 几何＋空间RBF | 3.803 | 11.822–24.308 | 5.409–12.332 |
| 几何＋空间×头角RBF | 2.802 | 12.872–23.782 | 6.296–14.135 |
| 几何＋共享/头角加性RBF | 2.715 | 9.422–21.206 | 4.917–14.105 |

尾段留出前按训练CV选中conditional（空间长度100mm、角度5°、ridge0.1）。additive尾段分数更低，但不据此反向更改选择。所有方案均未达到P95<1mm。

现有角度[-10,-25]、[0,-20]、[10,-25]位于三角形顶点。整姿留出后剩两个角度，测试角均在其线段凸包之外；这些是困难的外推诊断，不能冒充密集网格内的插值认证，也不能只看同头姿尾段成绩就声称任意头姿有效。

## 合成验证

17项软件测试通过，新增验证：恢复自由pF与X、未训练角度的刚体预测、连续角度核平滑/半正定、预测不依赖pF/q7、未批准模型拒绝正式推理。

另构造12个训练头姿和6个未见插值头姿，加入已知平滑视场/角度偏差。120个新角度样本上，相对**合成真实位置**的P95：纯几何2.134mm，加性补偿0.391mm；相对拟合FK标签为2.082/0.543mm。说明该模型能处理指定合成条件，不是实机验收，也不保证任意未知误差分布。

## 怎样真正验收

proposed_acceptance_plan.json只给采集/验证设计，不执行硬件动作。初期12头姿网格覆盖yaw[-30,30]、pitch[-25,25]，另6个插值角完全留出；每姿建议30个训练球位，测试角采15个新球位，包含重复返回头姿、变化法兰姿态及独立日期的新会话。先核实固定头部几何/零位、角度反馈及机械重复定位，再扩大空间覆盖。

目标要求新球位、新头姿及新会话分别P95<1mm，同时报告RMS/max、拒绝率及支持覆盖。达标只适用于已验证角度/空间域，不能从±30°直接扩展宣称全±90°。头持续转动还需真实曝光时刻、可靠时钟及独立速度分档验证，停稳任意头姿合格不能替代。
