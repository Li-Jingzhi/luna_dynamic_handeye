# 固定橙黄色球外观与检测修复（2026-10-28）

根因：自动曝光与AWB每次启动重新适应，五秒后锁定的值随场景变化；黄球中心约99.9%像素存在通道饱和（本次自动基准帧），不是99.9%图像像素。轮廓检测还会先截取最大8个区域再做面积过滤，令金色臂/桌面挤掉球；亚像素边缘又强制剔除最低20%梯度，阴影一侧虽有有效边缘仍被删除，导致覆盖度260°而未达到270°。
