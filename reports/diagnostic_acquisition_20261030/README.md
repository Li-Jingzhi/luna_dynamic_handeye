# 2026-10-30 自动黄球诊断程序离线验证

程序入口和实机命令见[采集说明](../../data_collection/diagnostics/README.md)。当前未连接机器人或相机，未下发硬件命令，未采到实机诊断数据。使用现有黄球，不要求精密间距靶、机械球心夹具或人工摆位。

验证记录见[VALIDATION.json](VALIDATION.json)：根目录unittest共70项，64通过、6项原有测试跳过。完整合成流程完成光学15、视觉保持48、双向返回120、新位姿验收30，共213窗口、10,650个双目对；分析核验全部已保存窗口的50帧、逐眼唯一标识、冻结模型和PNG哈希。合成数据的两种FK验收通过标志均为false，不能当作实机精度结果。合成图是占位PNG，球检测输入由合成几何生成，不验证真实图像分割质量。

专项测试覆盖无`--run`时禁止SDK/SSH、双10ms及停稳屏障、运动步长/限位、四组自动流程、模型与图像篡改拒绝、完成会话只读续采、相机初始化失败仍释放机器人、拒绝帧保留及逐眼去重。源码可编译，独立相机服务不加`--run`能离线校验资产，不导入硬件GStreamer/VPI模块。

完整仿真暴露并修复两类规划问题：单关节请求投影后姿态变化过小，改为归一化可达零空间方向并记录真实七关节目标；跨位置冗余姿态累积漂移，改为每个新位置以共用起始构型作姿态参考，同时保留12°硬边界。

尚未验证：真实控制器跟踪精度、场景可达性/可见性、Orin VPI/GStreamer运行、真实PNG传输耗时和50帧门槛通过率。接机需先在清空的局部运动范围做单组试采。仅黄球的光学/视觉保持试验提供一致性证据，无法独立确认绝对尺度或区分真实编码器零位、工具球心和MDH误差。最终同时保留原始FK和有效零偏FK误差，禁止把后者的低误差冒充原始FK精度。
