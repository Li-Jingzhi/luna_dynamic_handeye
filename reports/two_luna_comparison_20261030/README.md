# 两台同型号Luna V2.0：同方法固定头姿补偿对照

2026-10-30。用户本轮明确确认：2026-10-18旧相机参数及旧数据来自另一台同型号Luna V2.0，本机数据为2026-10-28/29的新参数新数据。机器序列号尚未提供，这里依据用户确认标注机体来源。不能将两批解释为同一台机器相机重标定前后的因果实验。

## 相同方法与固定参考

与旧数据最低训练P95=1.399mm使用的具体方法完全相同：先拟合完整仿射（3×3线性+平移），再用相机XYZ高斯RBF拟合剩余原FK残差，核长度20mm、ridge=0.01。七轴额外零位为0，MDH不变，pF固定[0,0,101]mm；两台均按该数值形成球心标签，工具物理定义仍须分别验证。只用像素三角化XYZ推理，不输入关节q7。

各固定头姿独立拟合，不使用动态头链。旧4组共1202有效位置；本机轨迹A四组1254、B四组407、新九姿已采前四组586有效位置。相同算法和参数不等于相同轨迹、相同覆盖、相同夹具或相同采集条件。

## 可泛化精度与采样密度

固定同一方法做5折连续轨迹留出，每折重拟合仿射和RBF，剔除测试段两侧2个有效位置：旧机P95为7.291–7.798mm；本机A为11.185–11.820mm，B为2.716–2.955mm，新四组为5.838–6.564mm。这个固定方法与此前“外层训练内选择ridge/核长”的协议不同，因此其结果可能高于之前选参后的外层结果。

B虽然训练约0.1mm，未见轨迹段仍约2.7–3.0mm，未满足1mm。RBF在训练点上有本点核中心，较小ridge可以显著吸收本点残差；不同样本数量、点间距和残差复杂度都影响训练误差。只有训练残差很低不能证明相机、机械臂或整机更准确。

## 两台机器是否存在较大差异

当前证据支持两套实机测量系统/数据分布的误差模式不同，尚不能量化成稳定的“本机硬件比旧机差多少”。

- 名义MDH哈希完全相同，型号相同。型号和MDH表相同不代表实机轴零位、安装、载荷、工具原点和挠曲也一致。
- 校正测量f分别约399.786px和400.458px；基线分别59.538mm和60.477mm，差0.938mm、约1.58%。这体现各自标定安装参数不同，不证明其中一套参数错误。棋盘格训练RMS分别0.1183px/0.2047px，也不能代替独立尺度验收。
- 同为[0,-25]，纯刚体训练P95：旧机5.110mm、本机A6.384mm、本机B3.891mm、本机新轨迹5.012mm。相同本机不同轨迹也跨越约2.49mm，不能将A单批较大值当作整台机器更差。
- 关节构型覆盖没有对齐。对[0,-25]的每个本机点找旧机最近q（以七轴最大角差为距离），A/B/新轨迹的中位最近差分别29.194°/38.844°/55.016°，连最接近的一对也分别差12.373°/13.310°/14.844°，没有≤0.1°的匹配样本。这不是同关节姿态重复实验。
- 同型号之间可有真实个体差异，现有数据同时混入相机、夹具、轨迹/空间与构型、采集时间、曝光/检测和身体条件差异，不能唯一归因到零位或相机。不能将一台拟合的零位或残差场直接用于另一台。

合理结论：两台均有未补偿FK—视觉毫米级不一致；本机并非在所有数据上都显著更差。要评估个体差异，应使用同一套精密已知间距靶和固定球心夹具、相近头姿与臂构型/空间覆盖、统一曝光与重复协议，在各自独立标定后对比留出误差。每台分别校准并冻结模型，再采独立新会话验收。
