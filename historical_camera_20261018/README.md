# 旧相机参数与固定头姿误差分析

日期：2026-10-30。结论：另一台同型号Luna V2.0的旧参数旧数据，在不做关节零位修正、不加残差补偿时，固定视角仍有明显毫米级误差。四个头姿独立SE(3)刚体拟合的训练P95为5.110–5.312mm，5折轨迹分块留出P95为6.029–6.321mm。不能据此认定误差全部来自关节零位。

## 本地恢复

恢复来源为仓库提交 `fdcca2ac73004bf5977bc7a3daed9f41d39ce5f8`（新相机参数替换前的版本）。从本地Git对象以 `git show commit:path` 恢复原始字节，共22个文件；未覆盖当前运行参数或当前数据。原文件路径保留在 `snapshot/` 下，逐文件SHA256见 `RESTORE_MANIFEST.json`。该清单中涉及删除记录的7个文件均与 `reports/camera_migration_20261028/deleted_files.json` 匹配。

- `snapshot/configs/camera/`：原始鱼眼K/D/R/T、校正测量参数与测量契约。
- `snapshot/configs/robot/`：当时的MDH、球偏移、躯干安装与头安装配置。
- `snapshot/datasets/raw/`：2026-10-18三头姿JSONL、第四头姿固定视角JSONL、完成清单和示教轨迹。

- `snapshot/sources.json`、MJCF XML：用于原资产哈希和安装参考检查，不需要运行MuJoCo。

这里恢复的是Git中保存的参数、观测日志和轨迹。Git未保存旧棋盘格原始照片与逐帧目标原图，本目录没有这些图像，不能重新进行旧相机棋盘格角点检测或复核原球轮廓。

旧相机有效棋盘格37对，基线59.538mm，双目训练RMS0.1183px；这些是原标定指标，不是独立三维精度。

## 分析口径

固定pF=[0,0,101]mm，使用旧MDH及原关节反馈，所有附加零位修正为0。目标为原FK预测的**球心**，不是法兰原点。四个头姿/会话分别拟合一个相机到躯干的六参数刚体变换；不使用动态头链、不拟合pF、不加RBF/仿射/关节补偿、不按误差删点。

先核对原始日志的MDH/原始相机/校正相机哈希及质量契约，再用档案中已经做过球心投影修正的四像素重新三角化，不能重复修正。共1292条原记录，1202条有效、90条原始拒绝。每条有效记录为50帧融合；它们不是1202张独立单帧原图。

5折按固定头姿内的有效轨迹位置连续分块，训练剔除测试块两侧各2个有效位置，每折重新估计刚体外参；同位置的融合记录不拆帧。另提供按FK空间主轴和臂关节第一主成分分块的诊断，分组和每折索引写入results.json。历史数据已用于研究，本次是历史诊断，不构成新的独立验收。

## 如何解释

1. 用户于2026-10-30确认旧数据来自另一台同型号Luna V2.0。旧机固定视角约5mm训练P95，说明旧机同样存在毫米级不一致；两台机器不能解释为同机相机重标定前后的因果比较。固定视角分析没有调用头链。
2. 本次约6mm是同头姿轨迹留出结果；不能与旧动态模型2.xmm、自由pF补偿或新模型跨轨迹9.535mm混为同一指标。新相机与旧相机的轨迹、构型、会话不同，本报告不能给出相机重标定造成误差增减的因果结论。
3. 本次未拟合任何旧数据零位。新数据的零位修正效果不能直接套到旧数据，尤其不能直接将新轨迹拟合的角度写回控制器。
4. 误差可能来自FK零位/几何、工具偏移原点和方向、结构挠曲、相机度量及球心检测系统偏差；仅凭相机—FK残差不能唯一归因。共同刚体坐标变换不会改变欧氏误差。
5. 建议继续用厂家SDK同q FK对照、固定球心多构型与已知距离靶分离误差。若要研究旧数据零位修正，应在此冻结基线上另建实验、做分块与跨会话验证，并保留原FK结果。
