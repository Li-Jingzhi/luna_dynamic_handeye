# 机器人配置

- `luna_new.ini`：Luna控制器MDH等参数；动态头链以此文件为准。
- `ball_offset.json`：标定球相对法兰的偏置。
- `torso_mounts.json`：本次整理的躯干、双臂与头部安装参考关系。只保存结构参考，不自动改变现有算法输出坐标系。

## 变换约定

采用右手系、齐次列向量：`p_parent = parent_from_child_T @ p_child`，矩阵平移单位为**米**。源四元数为wxyz，矩阵由归一化四元数生成。源MJCF文件路径和SHA256保存在JSON中。

`S_MODEL`专指`Gento Luna_Leg_J6_Link`原点。三组原始安装偏置相对该系：

| 零位安装系 | 平移，mm | 近似旋转 | MJCF行 |
|---|---|---|---|
| 右臂首关节 | [0,-214.6,391.5] | Rx(+90°) | 62 |
| 左臂首关节 | [0,+214.6,391.5] | Rx(-90°) | 104 |
| 头部首关节 | [-13.496,0,498.98] | Rx(+90°) | 146 |

双臂MDH父系由首关节安装乘首段MDH逆推，约为右[0,-56,391.501]mm、左[0,+56,391.501]mm；JSON保存未取整矩阵。这是名义CAD/MDH对齐，不是独立实机测量。

头部第二模型关节相对第一个模型关节零平移，原点重合；该MJCF头链仅作结构参考。控制器头链使用yaw→pitch，不能将模型头关节安装矩阵直接当作控制器MDH父系安装矩阵。

`S_INTERFACE_CAD_REF`取模型胸部STL最低平面Z=182mm，XY=0、方向沿用S_MODEL，仅作显示参考；未确认其就是控制器机械接口。若选用此参考，原始安装位置的Z统一减182mm。

躯干到控制器头MDH父系、头末端到左相机的外参尚未确认，以`null`明确保留；没有混入未批准的诊断拟合结果。

详细出处见[固定偏置来源说明](../../docs/frame_offset_sources_20261023.md)。

## 当前头部混合六参数配置

`head_mount_v2.json`定义固定公共旋转中心与零位轴向，主头链为`Rz(yaw) @ Ry(-pitch)`。位置来自MJCF头中心；D=640mm不进入计算，也不做逆变换抵消。只标定H1到校正左眼的6参数X。配置、假设及结果见[六参数说明](../../docs/six_parameter_calibration.md)。torso_mounts.json中的历史unresolved字段只描述旧controller_mdh父系，不能与新H_ref混淆。
